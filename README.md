# ✦ NovaPad Nexus

Node.js ile Güvenli paylaşımlar dileriz😉😉

Telefondan bilgisayarını tamamen kontrol et. Ekran paylaşımı, fare/klavye kontrolü, dosya yönetimi ve daha fazlası — tek bir web arayüzünden.

## 🚀 Özellikler

- 🖥️ **Canlı Ekran** — Bilgisayarını telefondan izle (dokunmatik fare kontrolü)
- 📁 **Dosya Yöneticisi** — Klasör gez, dosya aç, indir
- 📋 **Pano** — PC ve telefon arasında metin kopyala-yapıştır
- 🔊 **Ses Kontrolü** — Ses seviyesi ayarla
- 🖼️ **Duvar Kağıdı** — Hazır galeriden seç veya kendi resmini yükle
- 📊 **Sistem İzleme** — CPU, RAM, sıcaklık, batarya, disk, ağ
- 🎬 **Hızlı Modlar** — Oyun, İş, Film Gecesi
- 🎥 **Medya** — Ekran fotoğrafı, kamera, ekran kaydı
- 🌀 **Eğlence** — Matrix, emoji yağmuru, sahte mavi ekran, doğum günü modu
- 📝 **Kod Yazıcı** — Telefondan kod yaz, PC'de VS Code'da aç
- 🔐 **Güvenlik** — QR eşleştirme + HTTPS + IP whitelist + loglar
